# Flappy Bird Vite

A modern, browser-based version of the classic Flappy Bird game, built with JavaScript and Vite. This project features responsive design, custom graphics, and gesture-based controls using your webcam (powered by MediaPipe Vision Tasks). Navigate the bird through pipes by raising and lowering your index finger, and start the game with a thumbs up!

## Features
- Classic Flappy Bird gameplay
- Play with hand gestures using your webcam
- Responsive design for desktop and mobile
- Fast development and build with Vite

## How to Run

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Start the development server**
   ```bash
   npm run dev
   ```
3. **Open the game**
   - Visit the URL shown in your terminal (usually `http://localhost:5173/`).
   - Click the start button to play, or use a thumbs up gesture to begin!

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
